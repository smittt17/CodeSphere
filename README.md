#  CodeSphere

A modern developer social platform built using React, Spring Boot, MongoDB Atlas, JWT Authentication, and Cloudinary.

##  Live Demo

Frontend:
https://code-sphere-kohl.vercel.app

Backend:
https://codesphere-backend-production-2d28.up.railway.app

---

## Features

- User Registration & Login
- JWT Authentication
- Create Posts
- Like Posts
- Comment System
- User Profiles
- View Other User Profiles
- Cloud Image Storage
- Responsive Design
- MongoDB Atlas Integration

---

## Tech Stack

### Frontend
- React.js

- Axios
- Tailwind CSS

### Backend
- Spring Boot
